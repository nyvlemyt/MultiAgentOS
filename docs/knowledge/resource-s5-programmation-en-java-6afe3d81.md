# S5 - Programmation en Java

## Summary

Ensemble de documents du semestre 5 portant sur la programmation en Java dans un contexte académique (EFREI). Comprend un projet 2024, deux versions d'un rapport (docx et pdf), et un TP noté Java.

## Fields/API

**name**: Projet 2024
**type**: PDF
**description**: Énoncé ou livrable du projet Java du semestre 5, année 2024.
**name**: Rapport
**type**: DOCX + PDF
**description**: Rapport rédigé en double format (éditable et rendu final) associé au projet ou aux TP Java S5.
**name**: TP 3 JAVA EFREI
**type**: PDF
**description**: Sujet ou corrigé du troisième travail pratique de programmation Java à l'EFREI.

## Constraints

- Contexte académique EFREI — les ressources sont probablement liées à un cursus d'ingénieur ou licence informatique.
- Les fichiers sont référencés par titre uniquement ; leur contenu détaillé n'est pas disponible dans la source fournie.

## Examples

- Projet 2024.pdf → livrable de projet Java S5
- TP 3 JAVA EFREI.pdf → exercice pratique de programmation Java (séance 3)
