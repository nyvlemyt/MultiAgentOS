# S7 - nosql — Tutorial MongoDB Install.pdf

## Problem

Install and launch a local MongoDB Community Edition instance (server + client) on Linux, macOS, or Windows without using a package manager.

## Solution

1. Download the MongoDB Community TGZ/ZIP archive from https://www.mongodb.com/download-center/community — select version, OS, and TGZ package. 2. Extract to a local folder (referred to as /path/to/mongo/). 3. Launch the server: `cd /path/to/mongo/bin && mkdir dataFolder && ./mongod --dbpath dataFolder` (use `mongod.exe` on Windows). Keep this terminal open. 4. In a second terminal, launch the client: `cd /path/to/mongo/bin && ./mongo` (use `mongo.exe` on Windows). 5. Verify with `help` and `db.help()` in the Mongo shell.

## Variations

Option 1 (official): follow the platform-specific guide at https://docs.mongodb.com/manual/installation/#mongodb-community-edition for package-manager-based installs. Graphical client alternatives exist (e.g., MongoDB Compass, referenced via https://stackoverflow.com/a/6691013).

## Pitfalls

Closing the server terminal kills the mongod process and drops all client connections. On Windows, use the .exe binaries instead of the Unix-style ./mongod and ./mongo invocations. Documents are stored in BSON (binary JSON); ObjectIDs are auto-generated by MongoDB if not declared explicitly.
