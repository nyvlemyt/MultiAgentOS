# S7 - Mathematics for Data Science

## Summary

Corpus de cours S7 couvrant les fondements mathématiques pour la data science : exercices TD/TP, bases théoriques (algèbre linéaire, optimisation, analyse) et probabilités & statistiques. Trois documents complémentaires destinés à un niveau post-bac scientifique (licence/master).

## Fields/API

**name**: Exercices TD/TP
**source**: GXBd54-exercices_TD_TP_students-2.pdf
**content**: Feuilles d'exercices pratiques et travaux pratiques pour les étudiants — applications des concepts mathématiques à des problèmes de data science.
**name**: Mathematics for Data Science
**source**: Mathematics_for_Data_Science-2.pdf
**content**: Cours théorique couvrant les outils mathématiques fondamentaux utilisés en data science : algèbre linéaire (vecteurs, matrices, décompositions), analyse (gradients, optimisation), et possiblement théorie des graphes ou analyse fonctionnelle.
**name**: Probabilité et Statistique
**source**: Probabilité_et_Statitsique-1.pdf
**content**: Cours de probabilités et statistiques : variables aléatoires, lois de distribution, inférence statistique, tests d'hypothèses — socle probabiliste pour le machine learning.

## Constraints

- Niveau S7 (semestre 7, bac+3/4) — prérequis mathématiques de licence supposés acquis.
- Les trois documents forment un ensemble cohérent ; les exercices s'appuient sur les deux cours théoriques.
- Les fichiers sont des PDFs étudiants — peuvent contenir des espaces de réponse vides.

## Examples

- Utiliser Mathematics_for_Data_Science-2.pdf pour revoir la décomposition SVD avant d'implémenter PCA.
- Consulter Probabilité_et_Statitsique-1.pdf pour les bases de l'inférence bayésienne.
- Compléter les exercices TD/TP pour valider la compréhension des concepts des deux cours.
