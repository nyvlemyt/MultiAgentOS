# S5 - Mathématiques pour l'informatique

## Summary

Ensemble de documents de projet universitaire (Efrei, semestre 5) portant sur les mathématiques pour l'informatique. Le sujet central est un projet d'analyse du réseau de métro, décliné en plusieurs livrables (documents PDF asset 1 à 4). Implique vraisemblablement la théorie des graphes appliquée à un réseau de transport.
