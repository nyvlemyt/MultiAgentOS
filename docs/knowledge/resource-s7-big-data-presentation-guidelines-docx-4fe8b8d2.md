# S7 - big data — presentation guidelines.docx

## Summary

Guidelines for the S7 Big Data final oral presentation: a 12-minute per-student slot covering dataset analysis, distributed systems labs, and critical reflection on Generative AI usage.

## Fields/API

**slot_duration**: 12 minutes total per student
**breakdown**: **presentation**: 7 minutes
**qa**: 4 minutes
**deliberation**: 1 minute
**presentation_sections**: **section**: MovieLens Data Analysis
**duration**: 3 minutes
**required_content**: - methodology summary
- main results
- challenges and key learnings
**section**: HDFS and HBase Labs
**duration**: 3 minutes
**required_content**: - approach
- key results
- insights gained
**section**: Critical Reflection
**duration**: 1–2 minutes
**required_content**: - lessons learned
- how Generative AI helped or hindered the work
- concrete examples and critical analysis of Gen AI usage
**bonus**: Show progress level in AWS Cloud Practitioner bonus lab

## Constraints

- Do not repeat details already present in the written report — focus on methodology, results, and critical thinking.
- Slot registration is first-come, first-served via an Excel file.
- Students must be ready to answer questions about their work during the Q&A.

## Examples

- A student spends 3 min explaining their MovieLens EDA pipeline and the bias they found in ratings, then 3 min demoing HDFS file ingestion and an HBase query result, then 1 min describing how ChatGPT accelerated their HBase schema design but introduced an incorrect column-family assumption they had to debug.
- Another student uses the last 30 seconds to show their AWS Cloud Practitioner badge progress screenshot.
