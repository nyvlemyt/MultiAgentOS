# S7 - anglais — Part 5 Practice Exercises.pdf

## Summary

Quick-reference cheat sheet of English grammar pairs and vocabulary confusables for French-speaking learners (S7 engineering English course). Covers determiners, quantifiers, prepositions, collocations, and near-synonym distinctions.

## Fields/API

**determiners_and_quantifiers**: **rule**: any → negative contexts; some → positive contexts
**rule**: anymore → negative clauses; still → positive clauses
**rule**: like → singular comparison; alike → plural comparison
**rule**: too much → positive/excess sense; enough → negative/insufficient sense
**rule**: amount → uncountable nouns (adverb follows); number → countable nouns
**rule**: such → precedes noun (+ adjective); so → precedes adjective alone
**rule**: between → exactly 2 items; among → more than 2 items
**rule**: few → modifies uncountable nouns (adverb follows); little → modifies countable nouns (noun follows)
**verb_collocations**: **verbs**: - have
- take
- make
**note**: high-frequency collocate verbs — context-dependent choice
**noun_confusables**: **group**: - bill
- fee
- fare
**note**: bill = invoice; fee = professional charge; fare = transport cost
**group**: - crumb
- pat
- loaf
**note**: bread-related quantities: crumb (fragment), pat (small slab, e.g. butter), loaf (whole)
**group**: - aisle
- lane
- line
**note**: passage types: aisle (interior corridor), lane (road division), line (queue/row)
**group**: - precedent
- reputation
- reception
**note**: near-synonyms for established standing/image
**adjective_confusables**: **group**: - retired
- dismissed
- reduced
**note**: job-status terms: retired (left voluntarily/age), dismissed (fired), reduced (hours/pay cut)
**group**: - arduous
- reluctant
- advantageous
**note**: arduous = very difficult; reluctant = unwilling; advantageous = beneficial
**group**: - late
- deep
- high
**note**: dimension/position adjectives — context-dependent
**group**: - achieved
- accomplished
- acted
**note**: past-participle near-synonyms for completion/performance
**verb_confusables**: **group**: - anticipate
- signify
- renovate
**note**: anticipate = expect in advance; signify = mean/indicate; renovate = restore/refurbish
**rule**: say vs tell: tell requires a direct object (person told); say does not — 'she said …' vs 'she told me …'
**rule**: listened to (not *listened): 'listen' requires preposition 'to'

## Constraints

- Rules are prescriptive (exam-oriented), not exhaustive — edge cases exist in natural usage.
- few/little note in source appears inverted vs standard grammar; verify against course handout before applying.
- Collocate verbs (have/take/make) require collocation dictionaries for specific phrases — no exhaustive list provided here.

**negative**: I don't have any time.
**positive**: I have some time.

**positive**: She still works here.
