# S6 - Architecture des ordinateurs — Projet.pptx

## Problem

Afficher le nombre 1234 en langage Assembly, puis traduire ce programme en C, et rédiger un rapport documentant la démarche.

## Solution

1. Écrire un programme Assembly qui affiche '1234' (ex. via des appels système ou des instructions d'affichage selon l'architecture cible). 2. Traduire ce programme en C équivalent, en conservant la même logique bas niveau. 3. Rédiger un rapport expliquant les deux versions, les choix faits et les différences observées entre Assembly et C.

## Variations

Si le travail est fait sur papier, prendre des photos et les intégrer dans le rapport numérique.

## Pitfalls

Ne pas oublier de documenter chaque étape dans le rapport — le code seul ne suffit pas. Veiller à ce que la version C reste fidèle à la logique Assembly plutôt que d'utiliser directement printf sans expliquer la correspondance.
