# S5 - Python pour la Data Science — Python Data Science Séance 1.pdf

## Summary

Introduction au cours Python pour la Data Science (EFREI S5) : hiérarchie données→information→connaissance, typologies de données, processus OSEMN, 4 types d'analyses, techniques ML classiques, et écosystème Python (Pandas, NumPy, Scikit-learn, etc.).

## Fields/API

**name**: Hiérarchie de la connaissance
**description**: Données (brutes, vides de sens) → Information (organisée, contextualisée, répond à qui/quoi/où/quand) → Connaissance (expérience accumulée, répond à comment, sert à la prise de décision).
**name**: Types de données par structure
**description**: Structurées (tableaux, BDD relationnelles) · Non structurées (emails, médias, IoT — sans format prédéfini) · Semi-structurées (JSON, XML, HTML — balises partielles).
**name**: Types de données par nature
**description**: Vectorielles · Séquentielles · Temporelles · Spatiales. Valeurs : discrètes (binaires, énumératives, ordinales), continues (entières/réelles), dates, textuelles, multimédia.
**name**: Formats courants
**description**: CSV (tables texte) · JSON (semi-structuré, léger) · SQL (bases relationnelles).
**name**: Définition Data Science
**description**: Domaine multidisciplinaire (maths, statistiques, informatique, IA) pour extraire connaissances et insights de données structurées et non structurées. Questions couvertes : Que s'est-il passé ? Pourquoi ? Que va-t-il se passer ? Que faire ?
**name**: 4 types d'analyses
**description**: 1. Descriptive — ce qui s'est passé (visualisations : camembert, histogramme). 2. Diagnostique — pourquoi (drill-down, corrélations). 3. Prédictive — ce qui va se passer (ML, modèles prédictifs). 4. Prescriptive — quelle action optimale (réseaux neuronaux, moteurs de recommandation).
**name**: Processus OSEMN
**description**: O — Obtenir les données (BDD, API, web, tiers). S — Scrub/Nettoyer (valeurs manquantes, doublons, formats). E — Explorer (statistiques descriptives, visualisations, patterns). M — Modéliser (algorithmes ML : association, classification, clustering). N — iNterpréter (graphiques, tableaux, recommandations aux parties prenantes).
**name**: Types de problèmes ML
**description**: Classification (catégorie : spam/non-spam) · Régression (valeur numérique : prix) · Clustering (regroupement non supervisé) · Détection d'anomalies · Recommandation.
**name**: Préparation des données
**description**: Nettoyage : valeurs manquantes (suppression ou imputation par moyenne/médiane), doublons, erreurs typographiques. Transformation : normalisation (même échelle), encodage (catégoriel → numérique). Division : jeu d'entraînement (ajuster le modèle) / jeu de test (évaluer la performance).
**name**: EDA — Analyse exploratoire
**description**: Statistiques descriptives (moyenne, médiane, écart-type). Visualisations : histogramme (distribution continue), boxplot (distribution + outliers), scatterplot (relations entre variables). Détection outliers. Corrélation (coefficient de corrélation).
**name**: Modèles classiques
**description**: Régression linéaire (variable continue) · Régression logistique (binaire) · KNN · Arbres de décision · Random Forest · ML supervisé (données entrée+sortie) · ML non supervisé (clustering, patterns cachés).
**name**: Métriques d'évaluation
**description**: Précision (proportion prédictions correctes) · Recall (capacité à identifier les vrais positifs) · F1-Score (moyenne harmonique précision/recall) · Validation croisée (test sur plusieurs sous-ensembles).
**name**: Bibliothèques Python Data Science
**description**: Pandas (manipulation/analyse) · NumPy (calcul numérique, matrices) · Matplotlib / Seaborn (visualisation) · Scikit-learn (ML classique) · TensorFlow / PyTorch (deep learning).
**name**: Python — caractéristiques clés
**description**: Syntaxe lisible, proche du langage humain · Interprété (prototypage rapide) · Polyvalent (web, data, automatisation) · Cross-platform (Windows, Mac, Linux) · Écosystème riche (Pandas, Django, Flask, Scikit-learn).
**name**: Secteurs d'application
**description**: Entreprise (recommandations e-commerce, stocks) · Divertissement (recommandations personnalisées) · Finance/Banque (fraude, assistants virtuels) · Santé (épidémies, wearables) · Télécoms · Services publics (compteurs intelligents).

## Examples

- Analyse descriptive : pics de réservations de vols par mois.
- Analyse diagnostique : pourquoi un pic de réservation vers une ville (événement sportif mensuel).
- Analyse prédictive : prévision de pics de réservation en mai pour cibler la pub dès février.
- Analyse prescriptive : optimiser le budget marketing sur différents canaux pour maximiser les réservations.
- Classification : spam/non-spam, commentaires positifs/négatifs/neutres.
- Régression : relation entre satisfaction client et nombre d'employés.
- Clustering : regrouper clients à comportement d'achat similaire.
