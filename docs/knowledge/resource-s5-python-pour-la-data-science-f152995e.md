# S5 - Python pour la Data Science

## Summary

Module S5 de formation Python pour la Data Science, couvrant les outils fondamentaux de l'écosystème data Python : NumPy pour le calcul vectoriel, Pandas pour la manipulation de données tabulaires, et un projet appliqué sur le dataset Inside Airbnb.

## Fields/API

**name**: Inside Airbnb Data Dictionary v4.3
**type**: référentiel
**description**: Dictionnaire de données officiel du dataset Inside Airbnb (version 4.3) — décrit les champs, types et significations des colonnes du dataset utilisé dans le projet.
**name**: Projet Python Data Science
**type**: énoncé de projet
**description**: Sujet du projet fil rouge du module, probablement basé sur l'analyse du dataset Inside Airbnb (logements Airbnb).
**name**: Python Data Science Séance 1
**type**: cours / support
**description**: Support de la première séance de cours — introduction à l'environnement Python data science (Jupyter, bibliothèques, concepts de base).
**name**: TP NumPy
**type**: travaux pratiques
**description**: Exercices pratiques sur NumPy : tableaux multidimensionnels (ndarray), opérations vectorisées, indexation, broadcasting.
**name**: TP Numpy Fichier
**type**: fichier support TP
**description**: Fichier de données ou notebook accompagnant le TP NumPy (données d'entrée ou squelette de code à compléter).
**name**: TP1 Pandas
**type**: travaux pratiques
**description**: Premier TP Pandas : manipulation de DataFrame, chargement de données, sélection, filtrage, agrégations de base.

## Constraints

- Module universitaire / formation — les ressources sont des supports pédagogiques, pas une documentation de production.
- Le dataset de référence est Inside Airbnb v4.3 ; les exercices sont calés sur ce périmètre.
- Progression supposée : Séance 1 (intro) → TP NumPy → TP Pandas → Projet intégrateur.

## Examples

- Charger le dataset Inside Airbnb avec Pandas et explorer les colonnes décrites dans le Data Dictionary.
- Utiliser NumPy pour calculer des statistiques descriptives vectorisées sur les prix de nuitée.
- Filtrer les annonces Airbnb par quartier ou note moyenne avec des masques booléens Pandas.
