# S6 - Gestion de projet

## Summary

Module S6 consacré à la gestion de projet, regroupant des exercices pratiques (démarrage de projet, outils avancés) et des études de cas outillées (analyse SWOT et cycle PDCA appliqués au projet Glimpse).

## Fields/API

**name**: Exercice démarrage
**description**: Document couvrant l'essentiel pour lancer un projet : périmètre, objectifs, parties prenantes, premiers livrables.
**name**: Outils avancés
**description**: Exercice sur les outils de pilotage avancés : planification, suivi, indicateurs, gestion des risques.
**name**: Analyse SWOT — Glimpse
**description**: Grille Forces / Faiblesses / Opportunités / Menaces appliquée au projet Glimpse.
**name**: PDCA — Glimpse
**description**: Cycle Plan-Do-Check-Act appliqué au projet Glimpse pour l'amélioration continue.
**name**: TD 3
**description**: Travail dirigé complémentaire, exercice de synthèse ou de mise en pratique des méthodes du module.

## Constraints

- Contenu structuré autour d'un projet fictif ou pédagogique nommé Glimpse.
- Les documents sont des fichiers .docx et .pdf ; les détails internes ne sont pas accessibles sans lecture directe des fichiers.
- Module S6 implique un contexte formation / cours — les exercices sont à visée pédagogique, pas opérationnelle.

## Examples

- Utiliser l'analyse SWOT Glimpse comme modèle pour construire la SWOT d'un nouveau projet.
- Appliquer le PDCA Glimpse comme template de cycle d'amélioration continue sur une itération de projet.
- S'appuyer sur l'exercice 'outils avancés' pour choisir les bons indicateurs de suivi d'un projet en cours.
