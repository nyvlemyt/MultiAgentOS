# S7 - Datalakes and Data Integration

## Summary

Module universitaire S7 couvrant les Data Lakes et l'intégration de données. Comprend des cours théoriques (fondamentaux des Data Lakes, architectures), des travaux pratiques (TP1–TP6), des sujets d'examen (contrôle final, rattrapage, correction), un projet encadré avec documentation technique, des rapports étudiants (dont un rapport signé Melvyn POMMIER), et des fiches de synthèse. Le module aborde l'ingestion, le stockage, la gouvernance et l'exploitation des données hétérogènes à grande échelle.
