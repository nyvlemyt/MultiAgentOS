# S7 - nosql — Information.pdf

## Summary

Plan de rédaction et critères d'évaluation pour un rapport de projet NoSQL couvrant une technologie au choix, avec démonstration pratique de 5 minutes.

## Fields/API

**structure_rapport**: - 1. Introduction : présentation de la technologie NoSQL choisie
- 2. Installation (manuel d'installation)
- 3. Création et manipulation d'une base de données
- 4. Exploration de fonctionnalités avancées
- 5. Comparaison avec les technologies vues en cours
- 6. Conclusion (bilan de compétences)
**démonstration**: **durée**: 5 minutes
**contenu**: Lancement de l'application sur le PC + 2 à 3 exemples de requêtes
**note_finale**: Note de TP/Projet + Note Examen
**technologies_vues_en_cours**: - MongoDB — modèle document (JSON)
- Cassandra — modèle colonne
- Neo4J — modèle graphe
- Redis — modèle clé-valeur
**nouvelle_technologie**: Projet : technologie NoSQL au choix de l'étudiant (distincte des quatre ci-dessus)

## Constraints

- La technologie du projet doit être différente des quatre étudiées en cours (MongoDB, Cassandra, Neo4J, Redis)
- La démonstration est limitée à 5 minutes et 2-3 requêtes maximum
- Le rapport doit inclure un bilan de compétences en conclusion

## Examples

- Choix d'une nouvelle technologie NoSQL (ex. CouchDB, ArangoDB, DynamoDB) pour le projet, comparée aux quatre modèles du cours
- Démonstration : démarrer l'instance locale de la base, exécuter une requête d'insertion et une requête de lecture
