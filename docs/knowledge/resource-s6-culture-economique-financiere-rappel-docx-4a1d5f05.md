# S6 - Culture économique & financière — rappel.docx

## Summary

Rappel des structures fondamentales de l'analyse financière d'entreprise : compte de résultat (charges/produits), soldes intermédiaires de gestion (SIG), bilan fonctionnel (emplois/ressources), et calcul des équilibres financiers FRNG, BFR et trésorerie nette.

## Fields/API

**name**: Compte de résultat
**description**: Tableau à deux colonnes : Charges (exploitation, financières, exceptionnelles) vs Produits (exploitation, financières, exceptionnelles). Le solde est le Résultat Net.
**name**: R.N — Résultat Net
**description**: Solde final du compte de résultat : Total produits − Total charges.
**name**: SIG — Soldes Intermédiaires de Gestion
**description**: Cascade d'indicateurs de performance : Marge commerciale → Produit de l'exercice → Valeur ajoutée → EBE → REX → Résultat financier → Résultat exceptionnel → Résultat Net.
**name**: Bilan fonctionnel
**description**: Tableau Emplois / Ressources classé par cycle : Emplois Stables (actifs immobilisés) / Ressources Stables (capitaux propres + dettes financières) ; Actif circulant (créances clients) / Passif circulant (dettes fournisseurs) ; Trésorerie Active / Trésorerie Passive.
**name**: FRNG — Fonds de Roulement Net Global
**description**: Ressources Stables − Emplois Stables. Représente le fond disponible après financement des immobilisations.
**name**: BFR — Besoin en Fonds de Roulement
**description**: Emplois circulants − Ressources circulantes. Mesure le besoin de financement du cycle d'exploitation.
**name**: TN — Trésorerie Nette
**description**: FRNG − BFR = Trésorerie Active − Trésorerie Passive.
**name**: Cycles du bilan
**description**: Trois cycles structurant l'analyse : cycle d'exploitation (BFR), cycle d'investissement (emplois stables), cycle de financement (ressources stables).

## Constraints

- R.N = Total produits − Total charges
- FRNG = Ressources Stables − Emplois Stables
- BFR = Emplois circulants − Ressources circulantes
- TN = FRNG − BFR = Trésorerie Active − Trésorerie Passive
- Total Emplois = Total Ressources (équilibre du bilan fonctionnel)

## Examples

- Compte de résultat : Charges exploitation (salaires) + Charges financières (intérêts emprunt) vs Produits exploitation (ventes) + Produits financiers (dividendes) → R.N
- Bilan fonctionnel : si FRNG > BFR alors TN > 0 (situation saine) ; si FRNG < BFR alors TN < 0 (tension de trésorerie)
