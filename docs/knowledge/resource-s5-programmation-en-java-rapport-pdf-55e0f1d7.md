# S5 - Programmation en Java — Rapport.pdf

## Summary

Rapport de projet étudiant (L3 APP-LSI 3, janvier 2025) décrivant une application Java en ligne de commande avec un menu interactif exécutant des requêtes SQL. Le projet a été réalisé sous contrainte de temps, limitant le périmètre aux fonctionnalités essentielles.

## Fields/API

**auteurs**: - Simon Girard
- Melvyn Pommier
- Vincent Pierro
**formation**: L3 APP – LSI 3
**date**: 22 janvier 2025
**langage**: Java
**type_interface**: CLI (menu console)
**technologie_données**: SQL (requêtes via menu)
**lancement**: Ouvrir dans VS Code, raccourci Ctrl+Maj+V (README.md en aperçu), appuyer sur Espace après chaque choix pour réafficher le menu

## Constraints

- Contrainte de temps : seules les fonctionnalités essentielles ont été implémentées
- Interface console uniquement (pas de GUI dans la version livrée)
- Navigation : l'utilisateur doit appuyer sur Espace après chaque sélection pour revenir au menu

## Examples

- Améliorations identifiées mais non implémentées : interface graphique (accessibilité, outils visuels), options de filtrage/recherche avancées dans le menu, module de statistiques avec visualisations graphiques et analyse de tendances
